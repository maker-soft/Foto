# Экспорт Яндекс Метрики для анализа

В репозитории настроен GitHub Actions workflow, который получает агрегированную статистику счетчика Яндекс Метрики **111851028** и сохраняет ее как закрытый GitHub Actions artifact `yandex-metrica-export`.

## Что нужно сделать один раз

### 1. Создать приложение Яндекс OAuth

1. Откройте https://oauth.yandex.ru/client/new/
2. Выберите **Для доступа к API или отладки**.
3. Название: например `Photobook Metrica Export`.
4. Укажите свою контактную почту.
5. В доступах выберите только **Яндекс Метрика — чтение статистики / metrika:read**.
6. Создайте приложение.
7. Скопируйте **ClientID**.

### 2. Получить OAuth-токен

Откройте в браузере, где `<CLIENT_ID>` заменен на ClientID вашего приложения:

`https://oauth.yandex.ru/authorize?response_type=token&client_id=<CLIENT_ID>`

Подтвердите доступ из того Яндекс-аккаунта, который имеет доступ к счетчику 111851028. Скопируйте выданный OAuth-токен.

**Не отправляйте токен в чат и не добавляйте его в файлы репозитория.**

### 3. Сохранить токен в GitHub Secret

В GitHub откройте:

`maker-soft/Foto` → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

Имя секрета:

`YANDEX_METRIKA_TOKEN`

Value: вставьте OAuth-токен Яндекса и сохраните.

### 4. Запустить первый экспорт

Откройте:

`maker-soft/Foto` → **Actions** → **Yandex Metrica export** → **Run workflow** → **Run workflow**.

После завершения должен появиться зеленый статус. Внизу страницы запуска появится artifact `yandex-metrica-export`.

## Что экспортируется

По умолчанию выгружаются последние 90 дней:

- сводные визиты, пользователи, просмотры, отказы, глубина и длительность;
- динамика по дням;
- источники трафика;
- поисковые системы;
- страницы входа;
- популярные страницы;
- устройства;
- география;
- браузеры;
- цели и конверсии;
- параметры счетчика и список целей.

Экспорт содержит агрегированные отчеты. OAuth-токен в artifact не записывается.

## Автоматический режим

Workflow запускается автоматически один раз в сутки и хранит каждый artifact 30 дней.

## Файлы интеграции

- `.github/workflows/yandex-metrica-export.yml` — расписание и запуск;
- `tools/yandex_metrica_export.py` — получение отчетов через API Метрики.
